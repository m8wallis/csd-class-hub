HTML is the skeleton.

A webpage is a text file with labels. Those labels are tags. The browser reads them and builds the page you see. Click each part — you’ll always get the code on one side and the result on the other.

01 · Tags

Tags are labels in angle brackets.

The name inside the brackets tells the browser what this piece is. Most tags come in a pair: an opening tag to start, a closing tag with a slash to finish.

03 · Attributes

          
Attributes add extra instructions.

          

            They live in the opening tag, as a name and a value in quotes. The tag says
            what it is. The attribute says how — where a link goes, what an image
            is, which tab it opens.

Keep these four words

          
Tag, element, attribute, nest.
